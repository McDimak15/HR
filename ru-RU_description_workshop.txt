[h1] Homeward Ragnarok [/h1]
[h2] Аддон на Homeward Journey для Infernal Eclipse of Ragnarok [/h2]

Официальное DLC для [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3456517686]Infernal Eclipse of Ragnarok[/url], которое добавляет совместимость с [url=https://steamcommunity.com/sharedfiles/filedetails/?id=2930931197]Homeward Journey[/url]

Это DLC поддерживает следующие моды:
[list]
[*] [url=https://steamcommunity.com/sharedfiles/filedetails/?id=2930931197]Homeward Journey[/url]
[*] [url=https://steamcommunity.com/sharedfiles/filedetails/?id=2824688072]Calamity[/url]
[*] [url=https://steamcommunity.com/sharedfiles/filedetails/?id=2909886416]Thorium[/url]
[*] [url=https://steamcommunity.com/sharedfiles/filedetails/?id=2843112914]Secrets of the Shadows[/url]
[/list]

Это DLC добавляет:
[list]
[*] Совмещённые древа крафтов для оружий и аксессуаров
[*] 100+ изменений рецептов
[*] 75+ изменений оружий
[*] 50+ изменений аксессуаров
[*] Титульные экраны Infernum для боссов HWJ
[*] Изменения боссов
[*] Инфернальные реликвии боссов
[*] Истории боссов из Calamity для боссов HWJ
[/list]
